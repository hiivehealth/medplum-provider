# CUI access policy templates

These are Medplum `AccessPolicy` templates, not standard FHIR R4 resources or SUSHI-generated artifacts.

Project provisioning must replace `REPLACE_WITH_CONFIGURATION_ID` with the id of the project-scoped `Basic` CUI configuration before creating each policy. Do not upload these templates unchanged.

The FSH source and SUSHI-generated JSON for the CUI extension, profile, and example configuration are owned by the `hiive-fhir-resources` repository.
